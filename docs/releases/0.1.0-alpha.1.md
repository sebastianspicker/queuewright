# Queuewright `0.1.0-alpha.1`

This version is an unpublished prerelease for local Zammad configuration
design.

## Included

- offline validation for profile and desired-state schema versions `1.0` and
  `1.1`;
- deterministic symbolic plan compilation;
- local Queuewright Studio source;
- V1 project import and compilation;
- Blueprint V2 migration and graph compilation;
- minimal and university configuration examples;
- experimental connected-control primitives with injected transports.

## Limits

- no live tenant discovery or Zammad HTTP adapter;
- no tenant changes through the CLI or Studio;
- no hosted API, tenant-connected application, or container image; the Pages
  demo is a client-only build with bundled fictional data;
- no compatibility guarantee before `1.0.0`;
- browser drafts have no in-app deletion control.

Publication requires every check in
[`RELEASING.md`](../../RELEASING.md) to pass from the exact tagged commit.
